# X 中文垃圾号识别 / 一键静音·屏蔽

一个轻量的浏览器用户脚本（Tampermonkey），自动识别并静音/屏蔽 X（Twitter）上泛滥的**中文色情 / 引流垃圾号**——就是那些 `万达广场`、`蹲个弟弟`、`同城上门`、`点击主页`、`t.me/xxx 加我` 之类的回复机器人。

## 它和老式"屏蔽名单"插件有什么不同

老插件收集的是一份**已知坏账号名单**（按身份屏蔽）。但这些号是一次性的、每天批量新生成，名单永远追不上 → 打地鼠必输。

本工具**不维护名单**，而是像邮箱的垃圾邮件过滤器一样，对**当面出现的每个账号实时按特征判断**：

- 用户名是不是「英文名 + 一长串随机数字」（如 `@Catheri47071247`）
- 显示名 / 正文里有没有 `同城上门`、`寻固炮`、`点击主页`、`日泡平台`、`秒约` 等关键词
- 有没有 `t.me/` 电报链或 `xxx.top` 这类短引流域名
- 有没有 🌸✈️💕 这类装饰 emoji 堆砌
- **同一条推的评论区里，是不是「一批不同的号在说同一句话」**（v0.7.0 新增，见下）

命中特征到一定分数才出手 → 换 100 个新号也照样识别，规则只写一次。

### 「一批号说同一句话」是怎么认出来的（v0.7.0）

这类号最爱刷的是同一句话的**变体**：换个 emoji、换个两位尾码（`1e` / `2j`）、换个全角标点、换个繁体字。
脚本先把正文**归一化**——摘掉 `@提及` 和链接、去 emoji 和零宽字符、去标点空白、去掉那种一号一变的
1–3 位尾码——再看同一条推底下有没有 **≥3 个不同账号**落到同一条归一化文本上。是的话，这几个号都会被
标上 `簇×3` 作为复核证据。

> 🔴 **簇只加标记分，不会授权自动出手。** 真人粉丝团复读同一句梗，和垃圾号刷同一句广告，在
> 「同一句话 + 相似用户名」这两个输入上是分不开的。所以簇最多把它们标红请你自己看一眼；
> 自动模式该不该动手，仍然只看原来那套独立信号。

> ⚠️ 设计上**单看"名字+数字"不会屏蔽**，避免误伤那些真人 @ 机器人的正常账号。

## 不是 AI agent，不卡

运行时**没有 AI、没有独立进程**。它就是几 KB 的 JavaScript，由浏览器当作网页的一部分来跑，和广告拦截器一个原理，开销可忽略。AI 只用在"前期把特征提炼成规则"，不在日常回路里。

## 安装（约 30 秒）

1. Chrome 用户先安装 [Tampermonkey 扩展](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)。其他桌面浏览器可从 [Tampermonkey 官网](https://www.tampermonkey.net/)安装对应版本。
2. 打开 [安装脚本](https://github.com/vahnxu/x-spam-blocker/raw/main/x-spam-blocker.user.js)，Tampermonkey 会弹出安装/更新页面，点「安装」或「更新」。
3. 打开或刷新 x.com。疑似垃圾号会被红框标出；可以逐条点卡片上的「静音」按钮，也可以点右下角面板的「静音/屏蔽本页疑似(n)」（会先确认，并分批慢速执行）。默认动作是**静音**，可在面板上切成屏蔽。

> **关于自动更新**：脚本头里带了 `@updateURL` / `@downloadURL`，Tampermonkey 会**定期（默认每天）**回 GitHub 检查版本号，有新版会弹更新提示。
> ⚠️ 前提是你**从上面第 2 步的链接安装**（"从 URL 安装"）。如果你是把 `.user.js` 文件**下载下来再拖进 Tampermonkey**（本地文件安装），Tampermonkey 没有更新来源，**永远不会提示更新**——这种情况按第 2 步的链接**重新安装一次**即可切回可自动更新；也可在 Tampermonkey 面板手动点「检查用户脚本更新」立即检查。

## 装了却没反应？（Chrome 138+ 必看）

如果 Tampermonkey 里**显示脚本已安装、版本号也对**，但打开 x.com **没有任何红框、右下角也没有 `🛡` 面板** —— 多半是 **Chrome 的「允许用户脚本 / Allow user scripts」开关没开**。

Chrome 从 **138 版**起对用户脚本类扩展加了一道权限闸（默认关闭，且可能被某次 Chrome 自动更新重置）。开关一关，**所有油猴脚本都不会执行**，哪怕显示已安装。打开方法：

1. 地址栏进 `chrome://extensions/`，右上角打开「开发者模式 / Developer mode」。
2. 找到 **Tampermonkey** → 点「详情 / Details」。
3. 往下滚，打开 **「允许用户脚本 / Allow user scripts」** 开关。
4. 回到 x.com **刷新**。右下角出现黑色 `🛡 已处理 N` 面板（带「模式」「动作」等按钮）即代表脚本已在运行。

> 判断脚本"有没有真在跑"最快的办法：x.com 按 F12 看控制台，有 `[x-spam] v0.x.x 已启动` 这行就是在跑。

### 装完 0.7.0 面板还是旧样子？（从本地文件装过老版本的必看）

0.7.0 改了脚本名（多了「静音」和「模板聚类」），Tampermonkey 会把它当作**另一个脚本**装进去，而不是覆盖旧的。如果你以前是**下载文件拖进去**装的老版本，现在会有两个脚本同时启用，页面上看到的还是旧面板（写着「已屏蔽 · 模式:手动」）。处理：打开 Tampermonkey 面板「已安装脚本」，把版本号 0.6.x 的那一行**关掉或删除**，刷新 x.com，看到「🛡 已处理」加「模式 / 动作」按钮即是新版。从链接装的用户会原地更新，不受影响。

## 右下角面板：模式 / 动作 / 撤销 / 导出（v0.7.0 起不用再改源码）

以前要改模式得打开脚本改 `MODE`，而且**每次自动更新都会把你的选择冲掉**。现在全都在右下角
`🛡` 面板上点，选择存在浏览器本地（`localStorage`），**自动更新不会再冲掉它**。脚本顶部那几个常量
退化成「你从来没点过面板时的出厂默认值」。

| 面板按钮 | 作用 |
|---|---|
| **模式:手动 / 自动** | `手动`（默认，最安全）只标红 + 给按钮，你点了才动手；`自动` 命中独立信号就慢速自动处理。⚠️ 簇分不算进自动出手的门槛。 |
| **动作:静音 / 屏蔽** | **默认「静音」**。静音更轻、随时可撤销，且不会断掉互相关注关系；屏蔽更重，解除后关注关系不自动恢复。 |
| **静音/屏蔽本页疑似(n)** | 只批量处理当前页面已经标红的账号，按 handle 去重。先弹确认，每次最多入队 25 个，6–12 秒随机间隔慢速执行。 |
| **撤销最近一条** | 撤销**账本里记为成功**的最近那一条（静音 → `mutes/destroy`，屏蔽 → `blocks/destroy`）。⚠️ 见下方「撤销能做到什么、做不到什么」。 |
| **导出账本** | 把账本导成 `x-spam-ledger.json`，便于事后复核有没有误判。 |

### 为什么默认是「静音」而不是「屏蔽」

这个工具的真正目标是**手机上的评论区变干净**。静音和屏蔽都是 X 的**服务端账号级状态**，桌面上点一次，
手机 App 里同样生效——这是唯一能让手机端评论区安静下来的杠杆（手机装不了油猴脚本）。
两者里静音更轻、可逆，所以默认选它。

> 🔴 **静音在手机端的实际效果请你自己验一次**：在桌面静音一个垃圾号之后，去手机上刷新同一条推的
> 评论区，确认它的回复确实不见了。这一条**没有在开发过程中实测过**，属于待你验收的项。

### 撤销能做到什么、做不到什么

撤销只针对**账本里这一条记录**，它做的事就是调用对应的 `destroy` 端点。

> 🔴 **它可能会解除一层本来就存在的关系。** 假设某个号你几个月前就自己静音过，后来脚本又对他
> 执行了一次静音——X 那边是幂等的，返回成功，账本记 `ok`。这时你点「撤销」，解除的是
> **你原来那层静音**，而不是「把脚本的动作回退掉」。
> 脚本没有办法知道它动手之前你和这个人是什么关系，X 也不会告诉它。
> 所以撤销的正确心智是「解除现在这层关系」，不是「时光倒流」。

账本导出的 JSON 里带 `at` 时间戳和命中理由，误判复核请以它为准。

### 账本与限速（所有写请求共用一条队列）

- **账本**：每次动作先记一条 `intent`，成功后改成 `ok`，失败 `fail`，结果不明 `unknown`，撤销后 `undone`。
  存在 `localStorage`，最多 2000 条，超了从最早的开始丢（面板会提示「更早的记录已不可撤销」）。
  只有 `ok` 的能撤销。
- **限速**：单击、批量、撤销**走同一条队列**——随机间隔 6–12 秒，并且计**尝试次数**（不是成功次数）：
  每小时 ≤40、每天 ≤150，跨刷新有效。
- **出错即停**：碰到 `429 / 401 / 403 / 网络异常` 就**整队暂停、清空还没发出去的、面板显示原因，并且不会自己恢复**。
  已经发出去但结果不明的那条记成 `unknown`，不会当成成功。
  这些数字是保守的工程估计，不是 X 公布的安全阈值。
- **名额是在每条请求发出前才占的，不是排队时**：一条命令排进队列到真正发出去，中间可能隔着好几分钟。
  这期间另一个标签页、另一次批量都可能把名额吃掉，所以每次发之前都会重新读一遍计数再决定。
  同理，**离开这一页、把模式切回手动，都会立刻作废还没发出去的那些**。
- **多开标签页**：几个 x.com 标签共享一份「下次允许发送的时刻」，所以不会同时开火。
  ⚠️ **残余限制**：两个标签页在同一秒内读到同一个值时，仍可能各自发出一条——
  这是把「同时开火」压成「偶尔撞车」，不是分布式锁。要绝对稳妥就只开一个 x.com 标签页。
- **`localStorage` 用不了就完全不动手**：限速账本或节流时刻写不进去，就等于没有上限，
  这种情况下脚本只标记、不发任何写请求，面板会显示原因。
- **单条请求最多等 20 秒**：超时就中止、记成「结果未知」（超时不等于没生效）、并停队等你看一眼。
  没有这道闸的话，一条永远不返回的请求会把整条队列钉死——不再发、也不再报错。
- **账本跨标签页合并**：每次写账本前会先把磁盘上的读回来按记录 id 合并，
  所以另一个标签页刚记下的动作不会被这一个标签页覆盖掉（覆盖掉就等于那些动作再也撤不回来）。
  合并有两条规矩：**只有本标签页自己改过的那几条**才有资格盖过磁盘上的版本（否则一个开着不动的
  旧标签页会把别处已经推进到「成功」的记录打回「意图」）；**淘汰按时间从最旧的那头砍**
  （否则揣着一堆旧缓存的老标签页会把旧记录复活、把新的挤掉）。

> ⚠️ X 的自动化规则明文禁止脚本化操作网站。本工具因此**坚持人工确认前置 + 慢速 + 触顶即停 + 出错即停**，
> 并且**不做**无人值守巡逻（不自动滚动、不自动展开回复、不由簇触发自动出手）。要不要承担账号风险，是你的决定。

关键词列表都在脚本顶部，中文注释，可自行增删。

## 本地验证 / 维护

本 repo 带一个零依赖回归 harness，用来防止规则和 X DOM 适配退化：

```bash
npm test
```

它会直接读取当前 `x-spam-blocker.user.js`，验证：

- 测试页加载当前脚本，不嵌入过期副本。
- 启动日志版本号和 userscript metadata 一致。
- 新波无敏感词中文垃圾号会被标记，正常短回复不会被误伤。
- 同一垃圾号出现多次时，每个可见卡片都会标记；自动模式只去重写请求。
- X 先渲染 handle、后补全文本时，会按内容签名重新判断。
- `/settings/blocked*` 页面会注入已屏蔽账号 JSON 采集器。
- 3 个不同账号说同一句话会成簇并标 `簇×3`；单独 1 个、3 个普通账号、3 句不同的话都不标。
- 簇形成后，先前已经判过的同伙卡片会被回扫补标；但簇分**不会**让自动模式出手。
- 归一化对 emoji / 尾码 / 全角标点 / 繁体同形字 / `@提及` 位置的差异免疫。
- 真人引用了一条垃圾回复不会被连坐（连「只转发不配文」这种卡片里唯一正文就是引用内容的情况也不会）。
- 设置写进 `localStorage` 后重启仍生效；非法值回落默认；`localStorage` 抛错时退化成内存值并在面板提示。
- 账本 `intent → ok`，成功响应里的 `id_str` 会存下来；撤销打到对应的 `destroy` 端点；`fail` 的不给撤销。
- `429` 之后队列暂停且不会自己恢复；每小时尝试上限触顶后连队都入不了。
- 上限在**发出前**再查一次：入队时还剩 1 个名额、却排了 3 条，最终只会发出 1 条。
- 共享节流时刻没到就一直等，不存在「等够几次就放行」；等一半不算数。
- 请求挂住 20 秒会被中止并停队；派发链路里抛异常也会结清账本、停队，不会留下永远 `intent` 的记录。
- 另一个标签页写进账本的记录，不会被本标签页的写覆盖掉，也不会被旧缓存打回更早的状态；
  账本满了是砍最旧的，不是砍排在数组前面的。
- 被回收给另一个账号的卡片，不会留着写着上一个账号名字的「已静音」角标。
- 默认动作打的是 `mutes/users/create.json`（静音）而不是 `blocks`。
- 两种真实嵌套方向都覆盖：`cellInnerDiv > article > tweetText`（作者正文要能读到）
  与 `article > 引用块 > tweetText`（引用内容要被排除）。
- 模式切回手动、路由切换、`pushState`、另一个标签页改设置，都会作废还没发出去的条目；
  取消一条撤销**不会**把原来那条成功记录改成失败。
- 卡片按钮把动作绑在自己身上：以「静音」标出来的卡片不会因为面板切了就变成屏蔽。
- 掉到阈值以下的卡片会撤掉红框、角标和按钮；账本载入时会剔除损坏条目并压回 2000 条上限。

harness 自带**可控时钟**（`manualClock`，定时器要显式 `advance(ms)` 才跑）和**可编程 fetch**
（按序返回预设状态码/响应体），以及可预置、可抛错的 `localStorage` 桩。

手工看样式时，可直接打开 `test/fixture.html`；它引用当前主脚本，避免 fixture 和发布脚本分叉。

## 适用范围

- ✅ 桌面浏览器（Chrome / Edge / Firefox / Safari / Brave / Arc 等）
- ⚠️ 手机浏览器一般不支持扩展/脚本（iOS 需配合 Userscripts 等 App，安卓需 Firefox/Kiwi）。本工具定位为**桌面端**。

## 状态

早期版本。X 的页面结构和内部接口偶有变动，可能需要微调选择器。请先用默认「手动」模式验证准确率，再考虑开「自动」。

**v0.7.0 变了什么**

- 新增**模板指纹聚类**：认「一批号说同一句话」，不再靠追关键词变体。只作标记证据，不授权自动出手。
- 新增**动作可选**：静音 / 屏蔽，**默认静音**。
- **设置持久化**：模式 / 动作 / 阈值存在浏览器本地，不用再改源码，自动更新也不会冲掉。
- 新增**账本与撤销**：意图 → 结果两段记录，可导出 JSON，只撤销脚本自己成功执行过的。
- 新增**共享准入控制**：单击 / 批量 / 撤销共用一条限速队列，计尝试次数，出错即停不自动恢复。
- 修正**引用推文归属**：真人引用一条垃圾回复不再被连坐（两种嵌套方向都覆盖）。
- 多标签页共享节流时刻并合并账本；`localStorage` 不可用时只标记、不动手。
- 每条请求带 20 秒中止闸，超时/异常一律停队并如实记成「结果未知」。
- 🔴 **待你验收**：静音在手机 X App 上的实际效果尚未实测（见上文「为什么默认是静音」）。
- ⛔ **明确不做**：无人值守巡逻（自动滚动 / 自动展开回复 / 自动出手）、由簇触发的自动处理、X 关键词静音。

当前加固点：

- 事件驱动扫描，不做闲置轮询。
- 按卡片内容短签名复扫，适配 X SPA 异步渲染。
- 重复 handle 的可见卡片都会标记；自动屏蔽请求按 handle 去重并限速。
- 重复卡片联动置灰只保留最近窗口的 DOM 引用，避免长时间浏览内存膨胀。
- 覆盖城市矩阵刷屏、二维码/图片引流、`点击即可联系`、`附近喝茶`、`服务复制佳薇` 等中文批量垃圾话术。
- 覆盖短评 @ 引流形态：`她太涩/顶不住`、`主页能打`、`体制内老师/已探路/花样多`、`专业牵线/1-5线覆盖/看主页` 等。
- 只标记最外层可见卡片，避免 X 的 `article` / `cellInnerDiv` 嵌套导致重复 badge 和重复「屏蔽」按钮。
- 右下角支持确认后分批慢速屏蔽本页已标记账号，复用自动模式的去重和限速队列。
- 已屏蔽账号页可导出 JSON 正样本，用于后续校准中文批量垃圾号特征。
